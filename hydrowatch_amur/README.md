# HydroWatch Amur — набор данных кейса

Оперативный мониторинг гидрологической динамики по совместным данным Sentinel-1 и Sentinel-2.
Территория — Амурская область, 11 пар «район интереса x событие».

## Что нужно сдать

Файл `submission.csv` — одна строка на пару, четыре колонки:

```
pair_id,flood_ha,water_pre_ha,water_peak_ha
```

| Колонка | Что записывать |
|---|---|
| `pair_id` | Идентификатор пары из `sample_submission.csv`. Ключ, по нему сверяется результат |
| `flood_ha` | Площадь зоны нового затопления, гектары |
| `water_pre_ha` | Площадь водного зеркала на дату «до», гектары |
| `water_peak_ha` | Площадь водного зеркала на дату пика, гектары |

Набор `pair_id` должен совпадать с `sample_submission.csv`, порядок строк любой.
Площади неотрицательны, разделитель дробной части — точка или запятая.
`flood_ha` не может быть больше `water_peak_ha`. Пропущенная пара засчитывается как ноль.

Растровые маски затопления передаются организаторам отдельно, не через платформу:
по одному GeoTIFF на пару, `<pair_id>_flood.tif`, uint8, значения 0 и 1, та же сетка,
размер и проекция, что у растров пары.

## Структура

```
hydrowatch_amur/
  rasters/<event_id>/<aoi_id>/
    S1_*.json, SENTINEL2_*.json  паспорта сцен: дата, орбита, каналы — по ним выгружать снимки из GEE
    AUX_terrain_gsw.tif        slope, hand, occurrence, seasonality, max_extent, builtup
    ERA5_daily_*.csv           посуточные осадки, температура, снеготаяние
    *.json                     метаданные каждого растра: сенсор, дата, орбита, каналы
  reference_masks/
    reference_<pair_id>.tif    эталон, 5 каналов, uint8
    reference_<pair_id>.json   метаданные и площади по эталону
  vectors/
    amur_oblast.geojson        границы Амурской области
    aoi.geojson                полигоны районов интереса
    hydrography_osm.geojson    гидрографическая сеть OpenStreetMap
    basins_hydrosheds.geojson  водосборные бассейны HydroSHEDS
  tables/
    events_catalog.csv/.json   реестр событий: даты, реки, окна съёмки, описание
    scene_catalog.csv          каталог сцен Sentinel с датами и облачностью
  pairs.csv                    перечень пар: даты, орбиты, пути к растрам и маскам
  sample_submission.csv        шаблон посылки
```

Снимки Sentinel-1 и Sentinel-2 в архив не входят: участник выгружает их сам из Google Earth
Engine по датам из pairs.csv и паспортам сцен (коллекции COPERNICUS/S1_GRD и
COPERNICUS/S2_SR_HARMONIZED). Сетку задают эталонные маски: 10 м, EPSG:32652, от 3000 до 4500
пикселей по стороне. Выгрузку нужно привести к сетке маски соответствующей пары — маска
решения сдаётся в той же сетке.

## Эталонные маски

Пятиканальный GeoTIFF, uint8:

1. `flood` — новая вода: есть на пике, не было на дату «до», не постоянная
2. `water_pre` — вода на дату «до»
3. `water_peak` — вода на дату пика
4. `permanent` — постоянная вода, JRC Global Surface Water, occurrence не ниже 80 %
5. `receded` — ушедшая вода, диагностический канал

Оцениваются каналы `flood`, `water_pre` и `water_peak`. Разметка построена автоматически
по консенсусу радиолокационного и оптического признаков и сплошную ручную верификацию
не проходила — это ограничивает достижимую точность.

Маски выданы для обучения, подбора порогов и самопроверки. Формировать из них ответ
запрещено: площади в посылке должны быть получены расчётом по собственным маскам,
а репозиторий — воспроизводить присланный результат.

## Контрольные периоды межени

Пары события `baseline_2018_09_low` сняты в межень, затопления на них практически нет.
Они включены намеренно: по ним проверяется устойчивость решения к ложным срабатываниям.

## Дополнительные данные

Снимки Sentinel-1 и Sentinel-2 доступны в Google Earth Engine — коллекции
`COPERNICUS/S1_GRD` и `COPERNICUS/S2_SR_HARMONIZED`. Границы районов и даты пар выданы,
так что выборку можно расширять самостоятельно по другим событиям и годам.

## Лицензии

Данные Copernicus (Sentinel-1, Sentinel-2, Copernicus DEM) — открытая лицензия Copernicus.
JRC Global Surface Water, MERIT Hydro, HydroSHEDS, ESA WorldCover, OpenStreetMap —
по лицензиям правообладателей. Набор предоставлен для участия в соревновании;
публикация и передача третьим лицам запрещены.
